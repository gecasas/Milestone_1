#Printf
##Description

**Printf** is a 42 project whose goal is to recreate the function Printf from scratch.

The project helps develop a better understanding of these functions, as well as improve the use of pointers, dynamic memory, and structures in C.

Supported Conversions
%c	Prints a character
%s	Prints a string
%p	Prints a memory address in hexadecimal
%d	Prints a decimal number
%i	Prints an integer
%u	Prints an unsigned integer
%x	Prints a hexadecimal number in lowercase
%X	Prints a hexadecimal number in uppercase
%%	Prints the % character

## Instructions

The project includes a `Makefile`. To compile the library:

make


This generates printf.a.

Other available commands:

make clean
make fclean
make re


To use the library in another project:

#include "printf.h"


Then link printf.a when compiling.
