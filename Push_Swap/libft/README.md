#libft
##Description

**libft** is a 42 project whose goal is to create a C library from scratch, recreating basic functions for working with characters, strings, memory, conversions, and linked lists.

The project helps develop a better understanding of these functions, as well as improve the use of pointers, dynamic memory, and structures in C.

## Instructions

The project includes a `Makefile`. To compile the library:

make


This generates libft.a.

Other available commands:

make clean
make fclean
make re


To use the library in another project:

#include "libft.h"


Then link libft.a when compiling.

Library

libft contains functions implemented from scratch for:

Character manipulation.

String manipulation and searching.

Memory management and copying.

Type conversions.

Dynamic memory allocation.

Creation and management of linked lists.

The library is designed to be reused in future projects throughout the 42 curriculum.
